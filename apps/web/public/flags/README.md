# Bandeiras dos estados

Miniaturas PNG de 96 px de largura das bandeiras das 27 UFs, usadas no painel de cada serviço e nos grupos
por estado (ADR-18). Vêm do Wikimedia Commons: o arquivo de cada UF é o indicado pela propriedade P41
(bandeira) do item do Wikidata do estado. Todas estão marcadas como domínio público no Commons.

Os SVGs originais vão de 254 B a 352 KB; as miniaturas somam 74 KB. Para trocar uma bandeira, baixe a
miniatura de 96 px do mesmo arquivo do Commons e mantenha o nome `<uf>.png` em minúsculas.
